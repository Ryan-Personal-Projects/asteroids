# Asteroids

Asteroids is a project inspired by the classic arcade game. The goal is to navigate a spaceship, avoid asteroids, and achieve the highest score possible.

## Features

- Realistic physics-based movement
- Randomly generated asteroids
- Scoring system
- Retro-style graphics and sound effects

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/rrugh/asteroids.git
    ```
2. Navigate to the project directory:
    ```bash
    cd asteroids
    ```
3. Install dependencies (if applicable):
    ```bash
    # Example for Python
    pip install -r requirements.txt
    ```

## Usage

Run the game with:
```bash
python main.py
```
